Cara dashboard memetakan data SWS ke KPI

Catatan kualitas data

Baris SWS yang tidak konsisten. Baris ini tetap ditampilkan pada detail, tetapi tidak dihitung pada pencapaian kuartal bila tanggal deal kosong/di luar rentang wajar.

Cara memperbarui data mingguan

  1. Buka folder data/raw/ pada repositori GitHub ini.
  2. Klik Add file → Upload files, unggah file SWS terbaru (mis. SWS_W34__G2.xlsx), lalu Commit.
  3. GitHub Actions otomatis mengubahnya menjadi data/dashboard.json, lalu GitHub Pages menerbitkan ulang halaman ini — biasanya selesai dalam 2–3 menit.
  4. Muat ulang halaman; stempel minggu & tanggal di bagian atas akan berubah.

Halaman ini bersifat publik: siapa pun yang memiliki tautannya dapat melihat seluruh data yang ditampilkan. Untuk menyembunyikan kolom sensitif (no. telepon PIC, nilai kompensasi/branding, omset), ubah tampilkan_data_sensitif menjadi false pada config/scheme.json.
